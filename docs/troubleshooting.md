# Troubleshooting

Something went wrong on the way in. Find the line that matches what you see, and do what it says. Most of these take a minute.

One rule fixes many of them: after you install anything (Python, Claude Code, Git), **close Claude Code completely and open your Founder OS folder again**. An app that was already open keeps the old list of programs it can find, so it does not see what you just installed. On Windows, closing the window is not always enough: if a Claude icon stays in the tray (the small icons next to the clock), right-click it and choose Quit.

| What you see | What to do |
|---|---|
| Setup says Python is missing, or that your Python is older than 3.11. | Install the current Python from [python.org/downloads](https://www.python.org/downloads/). On Windows, tick **Add python.exe to PATH** in the first installer screen. Then close Claude Code completely (tray icon too, see above), open your Founder OS folder again, and say "set up Founder OS". Setup checks Python for you. If you want to check by hand, `python --version`, `python3 --version` or `py -3 --version` in a terminal should print 3.11 or higher. |
| Windows prints "Python was not found" and points you to the Microsoft Store. | That message comes from a Windows shortcut, not from a real Python. Install Python from python.org as in the line above. If the message still appears after that, type "app execution aliases" in the Windows search box, open that setting, and turn off the two entries named python.exe and python3.exe. Then close and reopen Claude Code. |
| Mac shows a pop-up asking to install the "command line developer tools". | Click **Not Now**. Install Python from [python.org/downloads](https://www.python.org/downloads/) instead, then close Claude Code completely and open the folder again. |
| Red "hook error" lines, or "python: command not found", every time a session opens or you send a message. | Those lines come from the OS's background helpers, which need Python. They are harmless and nothing is lost. Install Python as in the first line, close Claude Code completely, reopen the folder, and they stop. |
| The Start file says Claude Code was not found and opens the download page, or a terminal says `claude` is not recognized. | If you only have the Claude desktop app, that is expected: the app does not add the `claude` command. Open the app, go to the **Code** tab, choose **Local**, click **Select folder**, pick your Founder OS folder, and type "set up Founder OS". If you did install the terminal tool, close every terminal window and double-click Start again, because a new window is needed to find it. Still not found? Anthropic's [installation troubleshooting page](https://code.claude.com/docs/en/troubleshoot-install) covers it. |
| You double-clicked Start Founder OS while the ZIP was still open, or your answers did not save. | Windows can show a ZIP like a folder, but files opened from inside it run from a temporary copy. Close it. Right-click the ZIP, choose **Extract All**, open the extracted **Founder OS** folder, and double-click Start there. The Start file now stops and tells you when it is run from inside a ZIP. |
| Windows blocks the Start file. | If you see "Windows protected your PC", click **More info**, then **Run anyway**. The file is plain text: right-click it and choose Edit to read it first. If Windows says Smart App Control blocked it, there is no Run anyway button, and you should not turn Smart App Control off for this. Use the desktop app route instead: Claude desktop app, **Code** tab, **Local**, **Select folder**, pick the folder, type "set up Founder OS". |
| Mac says the Start file cannot be opened, or that Apple cannot check it. | Open **System Settings**, then **Privacy & Security**, scroll down, click **Open Anyway**, and confirm with **Open**. Those are Apple's current steps for blocked downloads. Or skip the file: open the folder in the Claude desktop app's **Code** tab and type "set up Founder OS". |
| "Unknown command: /founder-os:setup" (or any other `/founder-os:` command). | The `founder-os:` part only exists on a plugin install. On a ZIP or clone install, drop it: `/founder-os:setup` is `/setup`. Or skip commands and say what you want, for example "set up Founder OS". |
| You typed `/status` and got Claude's own account and version screen. | Claude Code has its own `/status`, and it wins on a ZIP or clone install. Say "check my OS readiness" instead. That runs the Founder OS readiness check. |
| Setup stopped halfway, you closed the window, or you hit a usage limit. | Nothing is lost. Setup saves its place after every phase. Double-click Start Founder OS again, or open the folder and say "continue Founder OS setup". It picks up where it stopped and does not ask again what you already answered. After a usage limit, wait until the time Claude shows you, then do the same. |
| You downloaded a new ZIP and your OS looks empty, or setup starts from the beginning. | You extracted the new ZIP into a new folder. Your data is still in your old folder. Open the old folder and say "update Founder OS". Never extract a new ZIP over your old folder: that replaces your own CLAUDE.md, rules and settings. |
| Strange characters, or a crash, when you write in Arabic or another non-Latin script. | Founder OS ships a setting that fixes this on Windows (`PYTHONUTF8=1` in `.claude/settings.json`). If it still happens, say "update Founder OS" and say yes to the change to `.claude/settings.json` when the update shows it. Then close Claude Code completely and open the folder again. |
| A push is refused with a message about a private remote. | Your OS holds your identity file, so once version history is on, it only pushes to a copy you have confirmed is private. Say "back up my OS": the backup step checks that your GitHub repository is private and confirms it for you. If you push by hand, make the repository private on GitHub first, then run `git config founderos.privateRemote origin` (use your remote's name if it is not `origin`). |

## Still stuck?

Email `solutions@arcassystems.com`. Say which install path you used (ZIP, plugin, curl or clone), whether you are on Windows or Mac, and copy the exact message you see. A screenshot helps.

More detail on each install path is in [install.md](install.md). Your first session is in [first-day.md](first-day.md).
